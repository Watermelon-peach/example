# 새싹 언어 문법

새싹은 파이썬처럼 **들여쓰기**로 블록을 나누는 한글 프로그래밍 언어예요.
나중에 드론 농사 게임에서 드론을 조종하는 데 쓸 거예요.

## 한눈에 보기

```
# '#' 뒤는 주석(설명)이라 실행되지 않아요
함수 팩토리얼(n):
    만약 n <= 1:
        돌려주기 1
    돌려주기 n * 팩토리얼(n - 1)

출력("5! =", 팩토리얼(5))      # 5! = 120

반복 3 번:
    출력("안녕")

과일들 = ["사과", "배"]
반복 과일 안에 과일들:
    출력(과일 + " 수확!")
```

## 값의 종류

| 종류 | 예시 | 설명 |
|---|---|---|
| 숫자 | `3`, `2.5` | 정수와 소수를 모두 '숫자' 하나로 다뤄요 |
| 문자 | `"안녕"`, `'안녕'` | `\n`(줄바꿈), `\t`(탭), `\"`, `\\` 를 쓸 수 있어요 |
| 참거짓 | `참`, `거짓` | |
| 없음 | `없음` | 값이 없다는 뜻이에요 (파이썬의 None) |
| 목록 | `[1, 2, "셋"]` | `목록[0]` 처럼 0번부터 꺼내요. `목록[-1]` 은 맨 끝이에요 |

## 키워드

| 새싹 | 파이썬 | 쓰는 법 |
|---|---|---|
| `만약` | `if` | `만약 x > 3:` |
| `아니면 만약` | `elif` | `아니면 만약 x > 1:` |
| `아니면` | `else` | `아니면:` |
| `반복` | `while` | `반복 x < 10:` (조건이 참인 동안) |
| `반복 … 번` | (없음) | `반복 5 번:` 또는 `반복 5번:` (정해진 횟수만큼) |
| `반복 … 안에` | `for … in` | `반복 i 안에 범위(10):` |
| `멈추기` | `break` | 반복을 바로 끝내요 |
| `건너뛰기` | `continue` | 이번 차례만 건너뛰고 다음 반복으로 가요 |
| `함수` | `def` | `함수 더하기(a, b):` |
| `돌려주기` | `return` | `돌려주기 a + b` |
| `통과` | `pass` | 아무것도 하지 않아요 (빈 블록 자리 채우기) |
| `그리고` / `또는` / `아님` | `and` / `or` / `not` | `만약 아님 비었음 그리고 x > 0:` |
| `참` / `거짓` / `없음` | `True` / `False` / `None` | |

## 연산자

- 계산: `+  -  *  /  //(몫)  %(나머지)`
- 비교: `==  !=  <  <=  >  >=`
- 넣기: `=  +=  -=  *=  /=`
- 문자에 `+`로 다른 값을 붙이면 자동으로 글자로 바뀌어요: `"개수: " + 3` → `개수: 3`

## 기본 함수

| 함수 | 설명 |
|---|---|
| `출력(값, …)` | 값을 화면에 보여 줘요. 여러 개면 빈칸으로 이어 붙여요 |
| `길이(목록 또는 문자)` | 개수를 알려 줘요 |
| `범위(끝)` / `범위(시작, 끝)` / `범위(시작, 끝, 간격)` | `범위(3)` → `[0, 1, 2]` |
| `추가(목록, 값)` | 목록 맨 끝에 값을 넣어요 |
| `꺼내기(목록)` | 목록 맨 끝 값을 빼서 돌려줘요 |
| `정수(값)` | 소수점 아래를 버리거나, `"12"` 같은 문자를 숫자로 바꿔요 |
| `문자(값)` | 값을 글자로 바꿔요 |
| `절댓값(숫자)` | |
| `최소(…)` / `최대(…)` | 숫자 여러 개나 목록 하나를 넣어요 |
| `무작위(시작, 끝)` | 시작~끝 사이 정수 하나를 골라요 (끝 포함) |

## 파이썬과 다른 점

- **함수 안에서 바깥 변수를 바로 바꿀 수 있어요.** 파이썬은 `global`을 써야 하지만,
  새싹은 같은 이름의 바깥 변수가 있으면 그 변수를 바꿔요. 없으면 함수 안에서만 쓰는 새 변수가 생겨요.
- 블록(`만약`, `반복`, `함수`)은 `:`로 끝나고, 다음 줄부터 **빈칸 4개**(또는 탭)만큼 들여써요.
- 비교를 `1 < x < 5` 처럼 이어 쓸 수 없어요. `1 < x 그리고 x < 5` 로 써 주세요.
